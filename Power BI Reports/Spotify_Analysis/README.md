Spotify Streaming Analysis Dashboard 🎧

Tools & Technologies:
Power BI for dashboard development
Excel or CSV as data source
DAX and built-in Power BI visual tools
Spotify Audio Features (danceability, energy, valence, etc.)


Problem Statement:
With millions of songs being streamed every day, understanding streaming patterns, artist popularity, and audio characteristics can help music platforms, marketers, and artists make data-driven decisions. The goal of this project is to analyze global streaming data to identify:

Top-streamed artists and tracks
Year-over-year trends
Audio feature breakdowns of popular songs
Artist collaboration patterns

| Section                           | Description                                                                    |
| --------------------------------- | ------------------------------------------------------------------------------ |
| 🎶 **Total Streaming Metrics**    | Shows total streams and average streams per track                              |
| 👑 **Top Artists & Tracks**       | Bar charts ranking most streamed artists and songs                             |
| 📈 **Streams Over Years**         | Line chart visualizing trends from 2016 to 2021                                |
| 🎧 **Audio Feature Analysis**     | Donut chart showing average values of features like danceability, energy, etc. |
| 🤝 **Artist Collaboration Ratio** | Pie chart comparing solo vs. collaboration tracks                              |
| 🗂️ **Interactive Filters**       | Dropdowns for Artist, Mode, Month, and Year                                    |


Analysis Process:

Cleaned and structured streaming dataset.
Merged additional audio feature data from Spotify.
Created calculated columns and measures (Total Streams, Avg per Track).
Designed interactive visuals to showcase:

Top performers
Temporal patterns
Song characteristics
Collaboration frequency


Findings & Insights:
The Weeknd emerged as the most streamed artist, with “Blinding Lights” being the top-streamed track.
Ed Sheeran and Lewis Capaldi consistently rank in the top 5.
Streaming peaked around 2016–2019, then showed a decline in 2020–2021.
Danceability (28%) and Energy (25%) are the most dominant audio features in top songs.
There’s an equal balance between solo tracks and collaborations (50–50), highlighting the rising trend of cross-artist releases.
