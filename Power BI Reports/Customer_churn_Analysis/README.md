Customer Churn Analysis Dashboard
Overview
This repository contains a comprehensive analysis of customer churn for a subscription-based platform. The goal is to understand key factors influencing churn, identify high-risk user segments, and recommend actionable strategies for improving customer retention.

The analysis includes:

An interactive Power BI dashboard visualizing user behavior, demographics, device usage, and churn patterns.

A detailed Word report outlining key metrics, problem areas, and business recommendations.

🔍 Problem Statement
Customer churn is a major challenge impacting recurring revenue and long-term growth. With a churn rate of 18%, this analysis aims to uncover:

Why users are leaving.

What patterns exist across devices, content preferences, age, and gender.

Which strategies could reduce churn and increase user retention.

📌 Key Features
Dynamic Filters: Analyze churn by gender, device, parental control, subscription type, etc.

Churn Rate Breakdown: Insights by device, age, and parental control status.

Content Preference Trends: Gender-based analysis of content consumption.

Monetary Metrics: Monthly revenue, total charges, and active subscription rate.

User Behavior: Device usage trends, rating averages, and engagement signals.
